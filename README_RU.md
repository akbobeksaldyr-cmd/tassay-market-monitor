# TASSAY Market Monitor — ежедневные цены Астаны (тестовый набор)

**Этот ZIP — прототип интеграции. Он не установлен на сайте и не гарантирует, что Arzan.kz разрешает или технически поддерживает автоматические запросы.** Если Arzan отдаёт страницу только через JavaScript, требует авторизацию или запрещает автоматический доступ, сборщик аккуратно записывает причину пропуска, но НЕ выдумывает цены.

## Какие товары

- TURAN, газированная 1 л, Астана — ссылка, предоставленная автором;
- Ессентуки №4, газированная 1 л, Астана — ссылка, предоставленная автором;
- TASSAY, газированная 1 л, Астана — предполагаемый путь из известной карточки Алматы; **нужно вручную подтвердить, что этот путь открывает именно Астану и этот товар**. Его можно заменить переменной `ARZAN_TASSAY_URL` в GitHub Actions, либо в `PRODUCTS` внутри `scripts/arzan_daily.py`.

## Что делает

1. GitHub Actions пытается проверить три страницы примерно в 09:07 по Астане (04:07 UTC; возможны задержки GitHub Actions).
2. Собирает цену **только** из раздела «Цены по магазинам» страницы с заголовком, совпадающим с брендом, газированностью и 1 л.
3. Сохраняет первый ежедневный снимок по комбинации день + бренд + магазин в `data/daily-prices.json`. Старые записи не удаляет, не перезаписывает и сохраняет ссылки.
4. Если проверить цену не удалось, сохраняет причину в `runs`; **не подставляет последнюю цену как новую**.
5. Автоматически добавляет endpoint `/api/auto-prices`, а на сайте — панель новых автоматических наблюдений со статусом «Ожидает проверки», и дополняет графики.
6. После коммита в `main` сайт обновится **только если** Render автоматически разворачивает новые коммиты; иначе понадобится ручной deploy.

## Как установить

Поскольку текущий доступ ассистента к GitHub только на чтение, файлы **не загружены** в репозиторий.

Содержимое ZIP нужно поместить **в корень существующего GitHub-репозитория**, сохранив пути:
- `.github/workflows/arzan-prices.yml`
- `scripts/arzan_daily.py`
- `scripts/install_arzan_integration.py`
- `data/daily-prices.json`

Далее в GitHub: Actions → **Astana daily Arzan monitoring** → Run workflow. Первый запуск внесёт интеграционные изменения в `app.py`, `km3.js`, `ru.html`, `index.html` и запишет результат проверки (или обоснование отсутствия цены). Проверьте логи Actions. Если «Workflows have read-only permissions», в Settings → Actions → General потребуется разрешение **Read and write permissions** для GITHUB_TOKEN (изменение настроек доступно только владельцу). Репозиторий может иметь дополнительные ограничения ветки main.

Важно: этот механизм **пока не прикрепляет снимки** магазина; автор сможет внести доказательства вручную. Не смешивайте подтверждённые автором и автоматически полученные данные.

## Приоритет: официальный доступ

Предпочтительно попросить Arzan.kz об API или разрешённой выгрузке цен для учебного проекта. Если они предложат API, замените HTML-парсер API-клиентом, сохранив структуру `data/daily-prices.json`.

## Заметки

- Программа уважает robots.txt, не обходит CAPTCHA, авторизацию или ограничения доступа.
- Если магазин не указан на странице товара, автоматическая строка для него не создаётся.
- Источник Arzan может показывать агрегированные цены со своей задержкой. `captured_at` означает **время чтения карточки**, не доказанное время изменения цены в магазине.
- Идёт запись только публичных предложений в KZT за 1 литр в Астане.
- Не заменяет исторические записи КМ1–КМ3.
