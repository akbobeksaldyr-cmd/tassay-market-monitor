# BSH4 — скриншоты этапа

Дата контрольной точки: 14.11.2026.

Итоговый этап: обоснованная правовая позиция, дополненные данные.

Загрузите сюда **реальные изображения интерфейса/таблиц именно данного этапа** через GitHub → **Add file** → **Upload files** → **Commit changes**.

Подходят .png, .jpg, .jpeg, .webp и .gif. Например: `BSH4_glavnaya.png`, `BSH4_ceny.png`, `BSH4_grafik.jpg`.

Если изображение сделано позднее по исторической версии, укажите в названии или пояснении, что это **реконструкция**, а не оригинальный скриншот того дня.

После загрузки изображения автоматически появятся на сайте в разделе «История исследования · БШ1–БШ4» через API GitHub (обычно через несколько минут), без изменения исходных цен. Не добавляйте пароли, персональные данные участников опроса и приватные документы.
